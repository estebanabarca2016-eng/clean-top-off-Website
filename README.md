# Clean Top Off Website

Clean Top Off informational / lead-generation website for private and corporate aviation fuel savings.

## Current structure
- Home
- About
- How It Works
- Benefits
- Pricing
- Contact

There is no customer login, username, password, account creation, or dashboard.

## Pricing
- $50 per tail per month
- $300 per tail per year
- Pricing page includes the assessment form directly beside the two plans.
- Contact page includes the same lead form.
- Form submissions are sent to info@cleantopoff.com through FormSubmit.
